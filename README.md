# CoWrite

CoWrite is a modern, distraction-free writing application focused on structured content creation, real-time editing, and a clean, customizable reading experience. It is built with a strong emphasis on type safety, maintainability, and scalable frontend architecture.

## Features

### Rich text editor powered by Tiptap
- Structured document state
- Extensible editor configuration
- Clean separation between editor logic and UI

### Type-safe frontend architecture
- Written almost entirely in TypeScript
- Uses TanStack Start’s type-safe routing
- Strong editor state modeling
- Predictable data flow and state updates

### Modern UI stack
- Tailwind CSS
- TanStack Start
- Custom theme tokens (no hardcoded colors)
- Minimal, readable layout optimized for long-form writing
- Mobile responsiveness with dynamic layouts based on screen size

## Tech Stack
- TanStack Start (with supporting TanStack libraries)
- TypeScript
- Tiptap
- Tailwind CSS
- CSS variables for theming
- LocalStorage-based theme persistence

## Getting Started

```bash
git clone https://github.com/your-username/cowrite.git
cd cowrite
npm install
npm run dev
```
